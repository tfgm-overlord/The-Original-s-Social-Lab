# Current Unknowns

This file is intentionally maintained as a first-class research artifact.

The lab does not treat an unresolved question as a hidden conclusion.

## State-integrity research

- Agent-level efficacy of a state/provenance ledger has not yet been established.
- It has not yet been established that graph storage is superior to versioned rows.
- It has not yet been established that provenance compaction preserves every auditability property we need.
- It has not yet been established how dependency invalidation should behave when a derived claim has both superseded and independent support.
- It has not yet been established how much provenance can be compacted before explanation quality materially degrades.
- It has not yet been established which existing systems already implement the complete behavior being investigated.

## Research discipline

When an unknown becomes testable, create an experiment rather than silently converting the unknown into a belief.

When an experiment fails, preserve the failure and update the relevant state explicitly.
