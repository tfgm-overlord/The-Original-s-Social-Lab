# Security Policy

## Scope

The Original's Social Lab (TOSL) is a public research repository. It is intentionally limited to public research artifacts and does not contain the private TFGM implementation, Pulse operational systems, credentials, secrets, or private operational data.

## Reporting a security issue

If you discover a security vulnerability in code or configuration contained in this repository, please do not disclose exploitable details in a public issue.

Use GitHub's private vulnerability reporting mechanism for this repository if it is available. If private reporting is not available, contact the repository owner through GitHub and provide enough information to reproduce and assess the issue without publicly exposing sensitive details.

Please include:

- the affected file, component, or workflow;
- the nature and potential impact of the issue;
- reproduction steps where safe to provide;
- any suggested mitigation, if known.

## Disclosure

Security reports are handled separately from the public research process. A security finding does not automatically establish a research claim, architectural conclusion, or validation result.

Do not publish credentials, tokens, personal information, private operational data, or private TFGM/Pulse implementation details in issues, pull requests, commits, or other public artifacts.

## Supported versions

The repository is currently an experimental research lab and does not maintain formal release versions. Security reports should reference the affected commit or branch when possible.
